# Penny design system

Penny uses a warm, cute stationery palette, chocolate text, sage accents and an original bunny mascot. The user's latest direction requires compact layouts and tinted cards and inputs throughout.

## Layout

Phone header: aligned bunny mark and wordmark, Premium crown and working bell. Bottom navigation: Home, Transactions, Reports, Wallets and Profile. The floating plus appears only on Home. Desktop uses a cream sidebar and the same content hierarchy.

Home contains a compact month selector, the selected wallet when more than one exists, three budget values, and envelopes with wallet-specific progress. Analytics belong to Reports. Transactions has a single-row search, a filter icon that expands options, small import/export icons and a compact editable ledger list.

Profile is a menu leading to individual pages for display, income/budgets, notifications, tips, data and legal details. Privacy, terms, about and deletion information are standalone public pages. First launch shows wallet onboarding, with no default wallet and no login requirement.

## Tokens

Canvas #FFF8EF, paper #F7ECE0, input fill #F1E2D2, ink #493B36, muted #705E53, primary #B95943, peach #F9E4D9, sage #68805D. Pure white cards and inputs are avoided. DM Sans for body and tabular money figures; Nunito for headings and wordmark. Spacing centers on 4/8/12/16/24px. Compact controls remain at least 44px where feasible. Corners range from 10px controls to 14px cards and 20px sheets.

## Forms and interaction

Themed selection controls and a custom calendar replace native dropdowns/date UI. Description is required and has an explicit bookmark to save it for reuse; saved descriptions are accessible with keyboard navigation. Calculator defaults to off and can be enabled in display preferences. No spending-type selector appears in transaction entry.

Currency is selected per wallet. Reports and budgets scope amounts to a wallet; mixed currencies are not added together. The icon picker starts with eight choices plus the current icon if necessary. Expand to all 16 free or all 40 Premium choices; free users see a compact faded preview and upgrade banner for the extra 24.

## Premium and reminders

The compact Premium screen uses the bunny, benefit grid, visible monthly price and a sign-in-first checkout button, with no duplicate Premium label above its heading. A visible themed code input with an arrow submit button grants verified lifetime access through the server. Monthly checkout states no trial, renewal and cancellation in Google Play; lifetime access has no renewal. The Profile membership button has a warm peach-to-honey gradient and a compact bunny. The header mascot crops to its readable face instead of shrinking the whole body. No fake entitlement or browser payment flow exists.

Tips are absent from the home content. Optional on-open tips appear only once per chosen day/week/month, with an always-available reading surface in the bell and Tips page. Native notification settings expose permission/schedule status and a real five-second test.

## Motion and accessibility

Short opacity/transform entrances, tactile button feedback and transform-based progress bars. Respect reduced motion. Maintain sufficient text contrast on tinted surfaces, visible focus, accessible form labels, modal focus containment and Escape dismissal. Avoid novelty or large promotional headings in routine app pages.

## Envelopes and page rhythm

Every envelope belongs to one wallet. Only the first wallet receives Food & drinks; later wallets start empty with an Add envelope prompt. Existing customized or used legacy groups are preserved and assigned to their wallets. Untouched legacy auto-created presets are retired. Headers share the canvas color, 44px period controls and a 12px gap before content. Mobile wallet selection uses its own row. Report amounts use three equal columns and charts use a single mobile column. Charts use deeper terracotta, blue, sage and plum with readable legend text. Profile footer has explicit padding.

Premium uses a peach-to-honey illustrated invitation, a compact four-benefit layout, a gold gradient offer, a terracotta gradient sign-in button, billing details and a visible code input. Wallet upgrades use the same gradients and bunny.
